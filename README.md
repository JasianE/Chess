# Chess

A browser-based chess game built in **2021**, focused on implementing core game logic and interactive UI using JavaScript.

## Overview

This project was created to challenge my problem-solving skills by building a more logic-heavy application compared to typical front-end projects. It involved handling game rules, piece movement, and board state management.

Developing this helped strengthen my understanding of state, edge cases, and structuring more complex logic in JavaScript.

## Features

- Fully playable chess game in the browser  
- Legal movement for all pieces  
- Turn-based gameplay (white vs black)  
- Visual board representation  
- Piece capture mechanics  

## Live Demo

https://chess-psi-pink.vercel.app/

## Tech Stack

- HTML  
- CSS (Vanilla)  
- JavaScript (ES6)  

## Challenges

- Implementing valid move logic for each piece  
- Managing board state and piece positions  
- Handling edge cases (captures, overlapping moves, etc.)  
- Keeping the UI in sync with game logic  

## What I Learned

- Structuring complex logic in JavaScript  
- Thinking through edge cases and constraints  
- Managing state without frameworks  
- Breaking down a large problem into smaller components  

## Development Notes

This was one of my earlier logic-heavy projects, so the focus was on correctness and functionality over polish. There are many opportunities for improvement (such as adding check/checkmate detection, better UI, or refactoring logic), but it was a major step forward in my coding ability at the time.

## Reflection

This project pushed me beyond simple UI work and forced me to think more like a problem solver. It was an important milestone in developing the ability to handle more complex systems and logic-driven applications.
